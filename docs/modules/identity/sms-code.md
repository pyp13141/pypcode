# POST /api/v1/auth/sms/send-code

> 契约同 [API §1.1](../../API.md#11-认证)。

## 说明

发送短信验证码。供应商 Mock：验证码打服务端日志（`[SMS-MOCK]`）；真实供应商接入见 D-006 附注。

## 请求（公开）

`{ "phone": "1xxxxxxxxxx" }` — 大陆手机号格式。

## 响应 200

`{ "expiresInMinutes": 5 }` — **固定响应，不泄露手机号是否已注册**。

## 错误码

| 码 | HTTP | 条件 |
|---|---:|---|
| `REQUEST_VALIDATION_FAILED` | 400 | 手机号格式不合法 |
| `AUTH_RATE_LIMITED` | 429 | 60 秒内重复发送 |

## 实现约束

- 验证码：6 位随机数，内存存储，5 分钟过期，最多错试 5 次，验证后即删（一次性）。
- 限流维度：手机号 → 1 次/60s。
