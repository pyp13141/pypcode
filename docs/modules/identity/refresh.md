# POST /api/v1/auth/refresh

> 契约同 [API §1.1](../../API.md#11-认证)。

## 说明

刷新会话：令牌轮换 + 盗用检测。

## 请求（公开）

`{ "refreshToken": string }`

## 响应 200

新令牌对（结构同 login 响应的令牌字段）。

## 错误码

| 码 | HTTP | 条件 |
|---|---:|---|
| `AUTH_REFRESH_INVALID` | 401 | 令牌不存在；或**已撤销的令牌再次出现**（盗用检测，同时撤销该用户全部会话） |
| `AUTH_REFRESH_EXPIRED` | 401 | 超过 30 天有效期 |

## 实现约束

- 成功刷新：旧会话置 revoked_at，创建新会话（旧 access 同步失效）。
- 盗用检测触发后客户端必须回登录页，不得重试。
